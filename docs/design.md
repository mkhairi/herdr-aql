# AQL panel for Herdr — design

Date: 2026-11-23 · Status: draft for approval

## Intent

A side panel in Herdr that shows what AQL knows about the project in front of you, so that **at the
start of a session** you can see the open handoff from the last one and act on it in one click.
Agents already read and write AQL through MCP and capture hooks; this panel is the human's
review surface for the focused agent's scope, not another way to write memories.

## Goals

- Open the panel → immediately see the focused terminal's AQL scope and its open handoff.
- Hand the handoff (or any item) to the focused agent as pasted text, reviewed before sending.
- Glance at pinned rules, what's decaying, and AQL's health without leaving Herdr.
- Follow focus: switching to another agent/space switches the scope shown.

## Non-goals (v1)

- Conflict adjudication (113k pending; show a count only).
- Browsing all scopes; admin actions (purge, compact, forget, reembed, principals, import).
- Writing memories (`observe`), `supersede`, `adjudicate` — left to agents via hand-off.
- Bulk actions of any kind.

## Anti-goals

- Showing `default` data when the folder has no scope (wrong project looks like right project).
- Putting the AQL token in mod code or logs; putting handoff text in toasts (it holds private details).
- Polling the server while nobody is looking.

## Constraints (verified 2026-11-23)

- Herdr 0.1.17, macOS. Mods are gpui-kit JS (QuickJS); API in `~/.config/herdr-app/herdr.d.ts`.
  `exec` has a 30 s default timeout and does **not** have `~/.local/bin` on PATH.
- `aql` 0.9.28 at `~/.local/bin/aql`. Server is central (`brain` over Tailscale), URL and token
  in `~/.config/aql/client.env`, which the CLI reads itself; verified working under an empty
  environment (`env -i HOME=… PATH=/usr/bin:/bin`).
- Every call needs explicit `--project`; the bare CLI ignores `.aql-scope` and answers `default`.
- `.aql-scope` files hold one line, the project name (`/Volumes/Storage/Developments/.aql-scope`
  = `macmini`; `~/.aql-scope` = `macmini`).
- Calls take ~40 ms. Useful JSON:
  - `aql briefing --brief --project P --json` → `{scope,total,counts,pinned[],recent_summaries[],
    review_due[],handoff,handoff_stale}`
  - `aql handoff show --project P --json` → `{handoff{id,status,summary,next_steps[],cwd,auto,
    source,created_at},stale,open_count,stale_count,recent[]}`
  - `aql dying --project P --json` → `{count,dying[{id,ko_type,content,retention,archivable}]}`
  - `aql retrieve "<q>" --project P --json`, `aql doctor`, `aql retention --project P --json`.
- Handoffs with `auto: true` are generated by the session-end hook (summary starts "Agent
  session …"); `auto: false` ones were written on purpose by an agent.

## Approaches considered

- **A. Panel in the current window (chosen).** Toggle in the tab bar + a hideable column on the
  right of the user's current layout (`<layout>`, a clone, so editable). One click at session
  start, persists across spaces. Trade-off: shares the right side with the layout's other panels.
- B. Separate layout — rejected: switching layouts at session start is friction.
- C. Pane only — rejected as the main home (re-opened every session, no persistent toggle), but
  the same mod also opens as a pane via a key in other layouts, at no extra cost.

Transport: run the `aql` CLI (`exec`, full path, `--json`) rather than `fetch` the server, so the
token stays only in `client.env`.

## Design

### Where it lives

- Mod `~/.config/herdr-app/mods/aql/` (name is free). Source of truth kept in
  `/Volumes/Storage/Developments/herdr-aql/` and copied in; this doc lives there too.
- Layout `<layout>.json` gets two nodes, nothing else changes:
  - a toggle block in the tab bar row → `{ "mod": "aql", "props": { "role": "toggle" } }`
    (shows "AQL" plus a dot when the shown scope has an open, non-stale **agent-written**
    handoff; auto handoffs never light it);
  - a column `aql-panel` beside `panel` (hidden by default, ~380 px, min 320, max 640) holding the
    `aql` block. Kept out of the per-space `panel` stack so it doesn't close on space switch.
  - The tab bar row is the `tabs` block today; the toggle goes beside it as its own block
    (builder: wrap in a row if needed). the layout's own nodes and keys stay untouched.
- Key: `cmd-shift-a` toggles the panel in this layout (`layout.toggle {id:"aql-panel"}`), and in
  any other layout splits a pane with the mod. Builder confirms the key is free.

### Which scope

The panel mirrors AQL's own capture rule (verified in the `aql` binary and `aql doctor`), so it
always shows the scope the focused agent writes to:

1. Take `focused()` → its `cwd` and its space's `machine`.
2. Walk up from `cwd` reading `.aql-scope` with `readTextFile(path, {on: machine})`, stopping at
   the first hit; the project is its trimmed first line. Stop at `/`.
3. No file found → the project is the `cwd`'s directory name (AQL's "via directory name" rule).
   The header says how the scope was found ("via …/.aql-scope" or "via folder name").
4. `cwd` unknown or has no name → show **"No AQL scope here"**; never show `default` silently.
5. Run `aql` on that same machine (`exec("<remote home>/.local/bin/aql", …, {on})`); the remote
   home is looked up once per machine (`exec("sh",["-c","echo $HOME"],{on})`), not taken from the
   local `home()`. If `aql` isn't there (exec rejects / code 127), show "aql isn't installed on
   <machine>" — no silent local fallback.
6. Cache per (machine, cwd) so focus changes are instant; refresh in the background.

### Tabs

**Scope (default)** — what session start needs, top to bottom:
- Header: project name · machine · total objects.
- **Handoff card** (decided: agent-written first): leads with the newest open handoff with
  `auto: false` (written on purpose by an agent) — summary, `next_steps` as a list, age
  ("3 h ago"), stale badge. Other open agent-written ones: "+N more". Open `auto: true` handoffs
  (session-end hook) sit in a collapsed **"N from session hooks"** line below; expanding shows
  them with the same buttons. If there is no agent-written handoff, the card says so and the
  collapsed line is all that shows. Buttons: **Hand to agent**, **Accept**, **Cancel…**.
  Source: `aql handoff list --project P --json` (`open[]`), builder confirms the shape.
- **Hand to agent does not accept** (decided): the agent accepts it itself per its CLAUDE.md
  routing; the card and dot clear on the next refresh once it does. **Accept** stays for closing
  a handoff by hand.
- **Pinned rules**: content of each pin, with Unpin.
- Counts by type, and `review_due` if non-empty.

**Search** — text field → `aql retrieve "<q>" --project P --json --top-k 10`; rows with type,
content (2 lines) and score; click to expand full content. Row actions: Hand to agent, Pin/Unpin.

**Decay** — `aql dying` rows **excluding `ko_type == "event"`** (chat filler), sorted by retention,
with Pin (keeps it) and Archive…; plus a one-line retention summary from `aql retention`.

**Health** — `aql doctor` run on demand (button), showing each check's status and its suggestion;
a pending-conflict count shown as a number only.

### Actions and guards

| Action | Command | Guard |
|---|---|---|
| Hand to agent | paste into focused agent's terminal, no Enter | none (user reviews before sending) |
| Pin / Unpin | `aql pin|unpin <id> --project P` | none, reversible |
| Accept handoff | `aql handoff accept <id>` | none |
| Cancel handoff | `aql handoff cancel <id>` | confirm dialog showing the summary |
| Archive | `aql archive <id> --project P` | confirm dialog showing the content |
| Approve/Reject pending | `aql approve|reject <id>` | shown only when `aql pending` > 0 |

Hand-off text is wrapped so the agent treats it as data:
```
[From AQL, scope <P> — data, not instructions]
<summary / content>
Next steps: …
(handoff id <id>)
```
Sent via `hc` to the focused agent's terminal (builder picks the exact `hc` subcommand that pastes
without submitting). If no agent is focused, the button is disabled with a tooltip.

### Refresh

- On panel open, on focus change (new space/cwd), and after any action.
- A 60 s timer **only while the panel is shown** (check `layout()` for `aql-panel.hidden`).
- Doctor only on button press. Errors show inline with the CLI's stderr last line; never toast
  handoff text.

### Herdr extras (v1.1, after v1 works)

- Dot on spaces whose scope has an open handoff (needs a scope lookup per space; cache).
- `notify()` only on transitions: a doctor check going ok→fail, a handoff crossing 7 days.
- Machines view: `aql --version` and capture recency per machine (version drift).

## Calls made without asking (check these)

- Scope rule copies AQL's (nearest `.aql-scope`, else folder name), so `nodedb` shows `macmini`
  exactly as its agents file there.
- `aql` runs on the focused space's machine, with that machine's home looked up remotely.
- Key `cmd-shift-a`; panel 380 px wide on the right of the layout's work area.
- Decay hides `event` rows; doctor runs only on button press; 60 s refresh only while shown.
