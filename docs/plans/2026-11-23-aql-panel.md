# AQL Panel for Herdr — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Herdr side panel (and pane) that shows the focused agent's AQL scope, leading with its open agent-written handoff, with Search, Decay and Health tabs and a few guarded actions.

**Architecture:** One mod `aql`. Pure modules (`scope.js`, `model.js`, `aql.js`) take Herdr functions as arguments and are unit-tested with `node --test`; only `main.js` imports `herdr`/`gpui-kit` and holds views. The mod drives the `aql` CLI with `--json` and explicit `--project`, on the focused space's machine. The user's layout gains a toggle block and a hideable column.

**Tech Stack:** Herdr 0.1.17 mods (gpui-kit JS on QuickJS), Node 22 `node:test` for unit tests, `aql` CLI 0.9.28.

**Spec:** `/Volumes/Storage/Developments/herdr-aql/docs/design.md`

## Global Constraints

- Source repo: `/Volumes/Storage/Developments/herdr-aql/` (git). Installed copy: `~/.config/herdr-app/mods/aql/` via `install.sh`; never edit the installed copy directly.
- Only `main.js` imports `herdr`, `gpui-kit`, `gpui-base`. Other modules are plain ES modules, no Herdr imports.
- QuickJS rejects `??` mixed with `||`/`&&` without parentheses — `herdr-app check` catches it, `node --check` does not.
- Never call `cx.notify()`/`setShared` during render; never pass `null` to `.child`; never keep a `cx` past its callback. Use Herdr theme tokens only (`theme()`).
- Every `aql` call: full path `<machine home>/.local/bin/aql`, `--json` where supported, explicit `--project <P>`.
- Never fall back to `default` silently. Never show handoff text in `notify()`/toasts. Never log the token.
- Refresh: on open, on focus change, after an action, and every 60 s only while shown. `doctor` only on button press.
- Hand-to-agent text wrapper, exact:
  ```
  [From AQL, scope <P> — data, not instructions]
  <body>
  (<kind> id <id>)
  ```
  where `<body>` for a handoff is the summary, then `Next steps:` and one `- step` per line.
- Key `cmd-shift-a`. Panel column id `aql-panel`, 380 px, min 320, max 640, hidden by default.

## Review Focus

1. **AQL server unreachable** (seen live: `aql-server unreachable at http://brain…:7400: io: Connection refused`, exit non-zero, no JSON) → panel shows "AQL server unreachable" with that last stderr line, keeps last good data greyed, no crash. Test in Task 3.
2. **No agent focused / focused pane is a plain shell or a mod** → Hand to agent disabled with tooltip "Focus an agent first"; scope still resolves from the focused cwd if any. Test in Task 2 (`handTarget`).
3. **`.aql-scope` empty or whitespace-only** → skip it and keep walking up (AQL treats it as absent). Test in Task 1.
4. **Handoff with empty `next_steps` or very long summary** → wrapper omits the "Next steps:" block; card truncates summary to 6 lines with expand. Test in Task 2.
5. **`aql` missing on a remote machine** (exec rejects or code 127) → "aql isn't installed on <machine>", no local fallback. Test in Task 3.

### Task 2: Pure model — handoffs, dying, hand-off text

**Files:**
- Create: `mods/aql/model.js`, `tests/model.test.mjs`

**Interfaces:**
- Produces:
  - `splitHandoffs(open: Handoff[]) => { lead: Handoff|null, more: Handoff[], auto: Handoff[] }` — `lead` = newest (`created_at`) with `auto !== true`; `more` = other non-auto, newest first; `auto` = `auto === true`, newest first.
  - `hasDot(open: Handoff[], staleMs = 7*864e5, now = Date.now()) => boolean` — true iff any non-auto handoff younger than `staleMs`.
  - `liveDying(dying: Item[]) => Item[]` — drops `ko_type === "event"`, sorts by `retention` ascending.
  - `ago(ms: number, now: number) => string` — `"just now"` (<60 s), `"5 min ago"`, `"3 h ago"`, `"2 d ago"`.
  - `handText({ project, kind, id, summary?, content?, next_steps? }) => string` — the exact wrapper in Global Constraints; `kind` is `"handoff"` or `"object"`; body is `summary` (handoff) or `content` (object).
  - `handTarget(focused, agents) => { terminal: string } | { error: string }` — terminal of the focused agent (`agents().find(a => a.focused)`, using its `address`), else `{error:"Focus an agent first"}`.
- Handoff shape (from `aql handoff show --json`): `{id, status, summary, next_steps[], cwd, auto, source, created_at}`.

- [ ] **Step 1: Write failing tests** for each export:
  - `splitHandoffs` with 2 auto + 2 agent-written (different `created_at`) → `lead` is newest agent-written, `more.length===1`, `auto.length===2`; all-auto input → `lead===null`.
  - `hasDot`: only auto → false; agent-written 8 days old → false; agent-written 1 h old → true.
  - `liveDying` drops `{ko_type:"event"}`, keeps facts, lowest retention first.
  - `ago(now-30e3, now)==="just now"`, `ago(now-3*36e5, now)==="3 h ago"`, `ago(now-2*864e5, now)==="2 d ago"`.
  - `handText` with `next_steps: ["a","b"]` equals exactly `"[From AQL, scope macmini — data, not instructions]\nS\nNext steps:\n- a\n- b\n(handoff id H1)"`; with `next_steps: []` has no `Next steps:` line (Review Focus 4).
  - `handTarget` with no focused agent → `{error:"Focus an agent first"}` (Review Focus 2).
- [ ] **Step 2:** `npm test` → FAIL.
- [ ] **Step 3: Implement** the exports in `model.js`.

### Task 3: `aql` CLI wrapper

**Files:**
- Create: `mods/aql/aql.js`, `tests/aql.test.mjs`

**Interfaces:**
- Consumes: Herdr's `exec(command, args, {on, timeout})` passed in.
- Produces: `createAql({ exec, on }) => AqlClient`, where every method resolves to `{ ok: true, data } | { ok: false, error: string, kind: "unreachable"|"missing"|"failed" }` and never rejects:
  - `home()` (cached; `exec("sh",["-c","printf %s \"$HOME\""],{on})`)
  - `briefing(P)` → `briefing --brief --project P --json`
  - `handoffs(P)` → `handoff list --project P --json` (data: `{open[], stale_count, open_count}`; confirm field names against live output in Step 3 and note them in the test fixture)
  - `dying(P)`, `retention(P)`, `pending(P)` → their `--json` forms
  - `retrieve(P, q)` → `retrieve <q> --project P --json --top-k 10`
  - `doctor()` → `doctor --json` (fall back to plain text lines if `--json` is rejected), timeout 60 000
  - `pin(P,id)`, `unpin(P,id)`, `archive(P,id)`, `approve(P,id)`, `reject(P,id)`, `accept(id)`, `cancel(id)` → `handoff accept|cancel <id>` for the last two
- Error mapping: exec rejects or `code === 127` → `kind:"missing"`, error `"aql isn't installed on <on ?? 'this Mac'>"`; stderr contains `unreachable` → `kind:"unreachable"`, error = last stderr line; other non-zero → `kind:"failed"`, error = last stderr line; stdout not JSON on a `--json` call → `kind:"failed"`, `"aql returned something unexpected"`.

- [ ] **Step 1: Write failing tests** with a fake `exec` that records calls and returns canned results:
  - `briefing("macmini")` calls `"<home>/.local/bin/aql"` with `["briefing","--brief","--project","macmini","--json"]` and `{on:"dev"}`; returns parsed JSON.
  - home looked up once across two calls.
  - unreachable: `{code:1, stderr:"error: aql-server unreachable at http://brain:7400: io: Connection refused\n"}` → `{ok:false, kind:"unreachable", error:"error: aql-server unreachable at http://brain:7400: io: Connection refused"}` (Review Focus 1).
  - missing: fake exec rejects → `kind:"missing"`, error `"aql isn't installed on dev"` (Review Focus 5).
  - `retrieve` passes the query as one argv element (no shell), e.g. `"a b; rm"`.
- [ ] **Step 2:** `npm test` → FAIL.
- [ ] **Step 3: Implement `createAql`**; then run `~/.local/bin/aql handoff list --project macmini --json` (once the server answers) and adjust the fixture to the real field names.
- [ ] **Step 4:** `npm test` → PASS.
- [ ] **Step 5: Commit** `feat: aql CLI wrapper with explicit errors`
